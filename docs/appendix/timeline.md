# 附录C 金融史大事年表

> 附录

本年表按时间顺序列出本书讨论过的主要市场事件、制度变化和思想史上的里程碑，并注明详细讲解的章节。它的用途有两个：一是查阅具体的时间；二是把分散在各章的案例放回同一条时间线上，看清楚它们之间的联系——例如 1985 年的广场协议、1989 年的日本泡沫顶点和 1997 年的金融危机，是同一个故事的不同阶段。

::: tip 阅读说明
- “地区”一栏：**日**＝日本，**中**＝中国（含香港），**美**＝美国，**欧**＝欧洲，**全球**＝跨地区的事件或思想。
- 指数点位为收盘价。日期以事件发生地的当地时间为准。
- 只收录书中讨论过的事件，因此并不是一部完整的金融史；读完后如果想了解更多，可以从第 55 章和附录 D 的书单入手。
- 2024 年以后的事件距今较近，它们的长期意义还有待观察。
:::

## 从年表中能看到什么

把这些事件放在一起，可以看到几个反复出现的模式（详细的讨论见第 20 章、第 46 章、第 51 章）：

1. **泡沫的结构相似**：新事物或新叙事 → 宽松的信用 → 价格上涨吸引更多人加入 → 杠杆增加 → 某个触发点 → 被迫抛售。郁金香、南海公司、1929 年、1989 年的日本、2000 年的互联网、2015 年的 A 股，细节各不相同，结构却很相似。
2. **杠杆、期限错配和失控的头寸是危机的放大器**：LTCM、雷曼、Archegos 靠借来的钱放大了头寸，硅谷银行和英国 LDI 栽在“短借长投”和利率风险上，巴林银行和住友商事则是一个人的头寸失去了控制——损失的规模往往不是由资产本身的下跌决定的，而是由杠杆、错配和内控的漏洞决定的。
3. **恢复的时间可能非常长**：道琼斯指数用了约 25 年、日经平均用了约 34 年才回到泡沫顶点（按价格计算；含股息时要短一些，第 51 章）。这是分散投资和控制杠杆的根本理由。
4. **制度在危机之后改变**：大萧条之后有了 SEC 和存款保险，安然之后有了萨班斯法案，日本的低 ROE 问题之后有了公司治理改革。了解制度的来历，有助于理解它为什么存在、还有哪些漏洞。
5. **骗局在每个时代都会换一个外表再出现**：从庞兹到麦道夫，从安愚乐牧场到 e 租宝和加密资产交易所，“高回报、低风险、说不清收益从哪里来”的组合从未消失（第 54 章）。
