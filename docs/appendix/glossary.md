# 附录A 术语表

> 附录

本表收录全书出现的主要术语，按主题分组，组的顺序大致与全书各部分对应。每个术语给出中文、英文、日文，一句话的简要释义，以及详细讲解它的章节。

::: tip 使用说明
- 用浏览器的页内搜索（Ctrl/⌘ + F）或本站右上角的搜索框，可以用中、英、日任何一种语言查找。
- 日文一栏是日本的金融机构、媒体和制度文件中**通常使用**的说法；同一个概念有多种说法时，用“、”隔开。日文与中文写法相同时也照样列出，方便确认。
- 释义只是提示，不是严格的定义。概念的前提、局限和争议，请回到对应章节阅读。
- 缩写词的完整形式写在英文栏中。
:::
