# 附录D 参考文献与延伸阅读

> 附录

本附录整理了正文中引用或提到的书籍、学术论文和数据来源，并注明引用它们的章节。

::: tip 使用说明
- **想找下一本读的书**：先看第 55 章的分级书单（入门 → 进阶 → 深入），那里说明了每本书适合谁、为什么值得读。本附录的 D.1 节是更完整的清单，不再重复推荐理由。
- **想核对书中的某个数字或结论**：在 D.2 节按章节找到原始论文，在 D.3 节找到数据来源。正文中的数字都注明了出处和口径；用最新数据重算时，结果可能与书中略有不同。
- D.1、D.2 中的章节号是正文**提到**该文献的章节；只出现在第 55 章书单中的书，只标第 55 章。
- 书籍的年份是原书初版的年份，很多书后来有修订版。有日文版或中文版的，尽量给出译名，方便查找；没有标注译名的，不代表没有译本。
- 学术论文的格式为：作者（年份）. 题目. 期刊. 期刊名用缩写，见本页末尾。很多论文可以在作者的个人主页或 SSRN 上免费阅读。
- 学术研究会被后来的研究修正甚至推翻（第 36 章的“因子动物园”、第 45 章的可重复性问题）。引用一篇论文，不等于它的结论已成定论。
:::
