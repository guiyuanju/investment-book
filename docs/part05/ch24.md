# 第24章 财务报表入门 🟡

> 第五部分 · 读懂企业：基本面分析

第 7 章说过，股票长期的价值取决于企业**未来能赚多少钱**。要判断一家企业未来能赚多少钱，第一步是看清它**过去和现在**是什么样子：拥有什么资产、欠了多少钱、一年卖了多少东西、赚了多少、钱从哪里来又花到了哪里。这些信息都写在财务报表（Financial Statements／財務諸表）里。

财务报表是商业的“通用语言”。它不难，但有自己的语法。本章先用一个虚构的小公司把三张表的逻辑讲清楚，再看会计规则给“利润”留下了多大的弹性，最后用任天堂 2026 年 3 月期的决算短信，演示如何拆解一份真实的财报。第 25 章会在此基础上讲各种财务比率，第 26 章讲如何识别造假。

## 24.1 资产负债表：企业拥有什么、欠什么

### 一个恒等式

资产负债表（Balance Sheet／貸借対照表，B/S）是企业在**某一个时点**（例如 3 月 31 日）的“快照”。它建立在一个永远成立的恒等式上：

$$\text{资产} = \text{负债} + \text{净资产（所有者权益）}$$

- **资产**（Assets／資産）：企业拥有或控制的、预期能带来经济利益的资源，例如现金、应收账款、存货、厂房设备。
- **负债**（Liabilities／負債）：企业欠别人的、将来要付出去的义务，例如应付账款、借款、债券。
- **净资产**（Equity／純資産）：资产减去负债之后剩下的部分，属于股东。

右边回答“钱从哪里来”（借的还是股东出的），左边回答“钱变成了什么”。所以资产负债表也叫“平衡表”：两边永远相等。

### 流动与非流动

资产和负债都按“多快能变成现金（或需要付出现金）”分类，通常以一年为界：

| | 流动（一年以内） | 非流动（一年以上） |
| --- | --- | --- |
| **资产** | 现金和存款、应收账款（売掛金）、存货（棚卸資産）、短期有价证券 | 厂房和设备（有形固定資産）、软件和商誉（無形固定資産）、长期投资（投資有価証券） |
| **负债** | 应付账款（買掛金）、短期借款、一年内到期的债务、应交税费 | 长期借款、公司债、退休金负债（退職給付に係る負債） |

### 读资产负债表要注意的几点

- **账面价值不等于市场价值。** 大部分资产按历史成本记账，再扣除折旧。一块 1970 年代买的东京土地，账上可能只有当年的买价；反过来，一台刚买的专用设备，如果拿去卖，可能远不值账面价格。
- **最有价值的资产往往不在表上。** 品牌、技术诀窍、客户关系、员工的能力，如果是企业自己培养出来的，通常不计入资产（第 27 章）。只有通过收购获得的部分，才会以“商誉”（Goodwill／のれん）等形式出现在表上。
- **净资产不是现金。** 净资产（尤其是其中的利益剰余金，即留存收益）是历年利润累积下来的“账面记录”，这些钱可能早已变成了厂房、存货或对子公司的投资。“企业的内部留保有几百万亿日元，所以手里有几百万亿现金”是常见的误解（第 25 章）。
- **日本的“純資産”与“自己資本”。** 日本的资产负债表上，“純資産”包括非控股股东权益（非支配株主持分）等；计算 ROE 时用的“自己資本”通常是不含这些部分的“属于母公司股东的部分”。两者一般相差不大，但读数据时要注意口径。

## 24.2 利润表：企业赚了多少钱

### 从收入到净利润

利润表（Income Statement／損益計算書，P/L）记录的是**一段时间**（例如一年）里企业的经营成果。它像一个“漏斗”：从收入开始，一层层扣除成本和费用，最后剩下净利润。

日本会计准则下的利润表结构如下（各层利润的名称是日本特有的，非常重要）：

| 项目 | 日文 | 含义 |
| --- | --- | --- |
| 营业收入 | 売上高 | 卖商品和服务得到的收入 |
| − 营业成本 | 売上原価 | 直接用于生产商品的成本 |
| = **毛利** | 売上総利益 | 产品本身赚多少钱 |
| − 销售费用及管理费用 | 販売費及び一般管理費（販管費） | 广告、销售人员和总部的工资、研发费用等 |
| = **营业利润** | 営業利益 | **本业**赚多少钱 |
| ± 营业外收益和费用 | 営業外収益・費用 | 利息收入和支出、汇兑损益、持股比例 20–50% 的关联公司的利润份额（持分法投資損益）等 |
| = **经常利润** | 経常利益 | 本业 + 财务活动的“经常性”利润 |
| ± 特别利润和损失 | 特別利益・損失 | 出售固定资产或投资证券的收益、减值损失、诉讼损失等**一次性**项目 |
| = 税前利润 | 税金等調整前当期純利益 | |
| − 所得税 | 法人税等 | |
| = **净利润** | 当期純利益 | 其中属于母公司股东的部分是“親会社株主に帰属する当期純利益” |

“经常利润”是日本特有的概念，日本的新闻和企业很重视它，但 IFRS 和美国 GAAP 没有这一层。中国的利润表没有“经常利润”，而是在附注中单独列出“非经常性损益”，并计算“扣除非经常性损益后的净利润”（俗称“扣非净利润”），用意相近：把一次性的项目剔除出去，看企业持续的盈利能力。

### 收入和费用在什么时候记账：权责发生制

利润表最重要的原则是**权责发生制**（Accrual Basis／発生主義）：收入在**商品或服务交付**时确认，而不是在收到钱时；费用在**与收入相对应的期间**确认，而不是在付钱时。

- 3 月卖出一批货、约定 5 月收款：收入记在 3 月，同时产生一笔**应收账款**。
- 花 1,200 万日元买一台能用 5 年的设备：不是在买的那一年记 1,200 万的费用，而是每年记 240 万的**折旧**（Depreciation／減価償却費）。

权责发生制让利润更好地反映企业“这一年做了多少生意”，但也带来了两个后果：第一，**利润不等于现金**；第二，确认收入和费用的时点、折旧的年限、坏账和存货的估计，都需要管理层的**判断**——这就是利润的“弹性”（24.5 节）。

### 一个简单的例子

为了把三张表串起来，下面用一个虚构的公司贯穿 24.1–24.4 节。

> **樱花咖啡公司**（虚构）在第 1 年年初成立：股东出资 1,000 万日元，从银行借款 500 万日元（年利率 4%），用 1,200 万日元买了咖啡机和店铺装修（使用 5 年，按直线法折旧）。这一年：
> - 销售额 3,000 万日元，其中 200 万日元是企业客户赊账，年底尚未收回；
> - 买入咖啡豆等原材料 1,300 万日元，其中 1,200 万日元在当年用掉（成为营业成本），100 万日元留作年底存货；买原材料的钱，年底还有 150 万日元没有付给供应商；
> - 工资、房租等费用 1,040 万日元，全部以现金支付；借款利息在年底以现金支付；
> - 税率按 30% 计算，年底以现金缴纳；年底向股东分红 100 万日元。

它第 1 年的利润表（单位：万日元，python 计算）：

| 项目 | 金额 |
| --- | --- |
| 营业收入 | 3,000 |
| − 营业成本 | 1,200 |
| = 毛利 | 1,800 |
| − 工资、房租等费用 | 1,040 |
| − 折旧 | 240 |
| = 营业利润 | 520 |
| − 利息费用（500 × 4%） | 20 |
| = 税前利润 | 500 |
| − 所得税（30%） | 150 |
| = **净利润** | **350** |

## 24.3 现金流量表：钱真正流向了哪里

### 为什么需要第三张表

利润是按权责发生制算出来的“账面成果”，而企业付工资、还债、分红，需要的是**现金**。一家利润很好看的企业，可能因为客户迟迟不付款、存货大量积压而资金链断裂——这叫“黑字倒闭”（黒字倒産）。

现金流量表（Cash Flow Statement／キャッシュ・フロー計算書，C/F）记录一段时间内现金的实际流入和流出，分成三类：

| 类别 | 日文 | 内容 | 健康企业通常的符号 |
| --- | --- | --- | --- |
| **经营活动现金流** | 営業活動によるキャッシュ・フロー（営業CF） | 卖商品收到的钱、付给供应商和员工的钱、缴的税 | **正** |
| **投资活动现金流** | 投資活動によるキャッシュ・フロー（投資CF） | 购买或出售设备、收购企业、买卖有价证券、定期存款的存取 | 通常为**负**（在投资） |
| **筹资活动现金流** | 財務活動によるキャッシュ・フロー（財務CF） | 借款和还款、发行股票、分红、回购 | 视情况而定 |

### 间接法：从净利润出发

大多数企业用**间接法**编制经营活动现金流：从净利润（日本通常从税前利润）出发，把“影响了利润但没有动用现金”的项目调整回来。以樱花咖啡为例（万日元）：

| 项目 | 金额 | 说明 |
| --- | --- | --- |
| 净利润 | 350 | |
| \+ 折旧 | \+240 | 折旧是费用，但这一年没有付出现金（现金在买设备时已经付了） |
| − 应收账款增加 | −200 | 记了收入，但钱还没收到 |
| − 存货增加 | −100 | 买了原材料，钱付了，但还没有变成营业成本 |
| \+ 应付账款增加 | \+150 | 记了成本，但钱还没付出去 |
| = **经营活动现金流** | **440** | |
| 投资活动现金流：购买设备 | −1,200 | |
| 筹资活动现金流：股东出资 + 借款 − 分红 | \+1,000 + 500 − 100 = \+1,400 | |
| = **现金增加额** | **640** | 年初现金为 0，年底为 640 |

用**直接法**验算：从客户收到 3,000 − 200 = 2,800，付给供应商 1,300 − 150 = 1,150，付工资房租 1,040、利息 20、税 150，经营现金流 = 2,800 − 1,150 − 1,040 − 20 − 150 = 440，结果相同。

这个例子说明了一个普遍规律：**营业收入增长快的企业，往往需要更多的营运资金**（应收账款和存货），经营现金流可能明显少于净利润。这本身不一定是坏事，但如果差距持续扩大、找不到合理的解释，就要警惕了（第 26 章）。

### 自由现金流

经营活动现金流减去维持和扩大业务所需的资本支出（设备投资，Capex），叫作**自由现金流**（Free Cash Flow，FCF）：

$$\text{自由现金流} \approx \text{经营活动现金流} - \text{资本支出}$$

樱花咖啡第 1 年的自由现金流是 440 − 1,200 = −760 万日元：开业的第一年，大笔设备投资让它“烧钱”，缺口靠股东和银行的钱弥补。之后几年，如果生意稳定，不需要再大笔投资，自由现金流就会转正。自由现金流是企业可以自由用于分红、回购、还债或新投资的现金，是估值中最重要的概念之一（第 25 章、第 30 章）。

## 24.4 三张表之间的勾稽关系

三张表不是孤立的，它们像齿轮一样咬合在一起。所谓**勾稽关系**（Articulation），就是指表与表之间必须相互一致的数量关系。樱花咖啡年底的资产负债表（万日元）：

| 资产 | | 负债和净资产 | |
| --- | --- | --- | --- |
| 现金 | 640 | 应付账款 | 150 |
| 应收账款 | 200 | 银行借款 | 500 |
| 存货 | 100 | **负债合计** | **650** |
| 设备（1,200 − 折旧 240） | 960 | 资本金 | 1,000 |
| | | 留存收益（350 − 100） | 250 |
| | | **净资产合计** | **1,250** |
| **资产合计** | **1,900** | **负债和净资产合计** | **1,900** |

可以看到四条主要的勾稽关系：

1. **利润表 → 资产负债表**：净利润 350 万减去分红 100 万，等于留存收益增加的 250 万。用公式表示：期末留存收益 = 期初留存收益 + 净利润 − 分红（再加减其他少数调整）。
2. **现金流量表 → 资产负债表**：现金流量表最后的现金增加额 640 万，等于资产负债表上现金的变化（0 → 640）。
3. **资产负债表的变化 → 现金流量表**：应收账款、存货、应付账款的变化，正是间接法里调整的营运资金项目；设备的增加对应投资活动现金流；借款和资本金的增加对应筹资活动现金流。
4. **折旧**：在利润表上是费用（−240），在资产负债表上让设备的账面价值减少（1,200 → 960），在现金流量表上被加回（+240）。

理解了勾稽关系，就能做两件事：

- **检查一致性。** 如果利润年年增长、留存收益不断增加，但现金和经营现金流迟迟不增加，钱一定“变成”了别的资产（应收账款、存货、预付款、无形资产……）。找到它变成了什么，就找到了分析的重点。
- **识别异常。** 很多财务造假都会在勾稽关系上留下痕迹。例如虚增的收入如果没有对应的现金流入，就会堆积成应收账款；如果伪造了现金，账上会出现“现金很多却还在高息借款”的怪现象（第 26 章康美药业的案例）。

## 24.5 会计准则与“利润”的弹性（日本会计准则、IFRS、美国 GAAP）

### 四套主要的会计准则

| | 日本会计准则（J-GAAP） | IFRS（国际财务报告准则） | 美国 GAAP | 中国企业会计准则（CAS） |
| --- | --- | --- | --- | --- |
| 制定者 | 企业会计基准委员会（ASBJ） | 国际会计准则理事会（IASB） | 财务会计准则委员会（FASB） | 财政部 |
| 使用者 | 大多数日本上市公司 | 欧洲等 140 多个司法管辖区；部分日本大企业（任意适用） | 美国上市公司 | 中国内地上市公司（2006 年以后与 IFRS 基本趋同） |
| 商誉 | **在 20 年以内摊销**；出现减值迹象时才做减值测试（先用未折现的现金流判断） | **不摊销**，每年必须做减值测试 | **不摊销**（上市公司），做减值测试 | 不摊销，做减值测试 |
| 一次性项目 | 设有“特别利益・损失”，并计算“经常利润” | **禁止**列示“特别项目”；没有“经常利润”；减值损失、资产出售损益等通常计入**营业利润** | 2015 年起取消了“非经常项目”的单独列示 | 在附注中披露“非经常性损益” |

日本从 2010 年 3 月期起允许上市公司任意采用 IFRS。根据日本交易所集团（JPX）的统计，截至 2026 年 9 月末，已经采用或决定采用 IFRS 的公司约 317 家，不到东证上市公司数量的十分之一，但大多是大企业：东证在 2025 年 8 月公布的分析显示，采用 IFRS 的公司（含计划采用）按市值计算约占全部上市公司的一半。丰田、索尼、软银集团、迅销等都采用 IFRS；任天堂等许多公司仍使用日本会计准则。所以，**比较两家日本公司的利润时，要先看它们用的是哪一套准则。**

一个典型的差异是**商誉**。假设一家公司花 1,000 亿日元收购了一家企业，产生了 600 亿日元的商誉：

- 在日本会计准则下，如果分 20 年摊销，每年要记 30 亿日元的费用，营业利润每年减少 30 亿日元；
- 在 IFRS 下，商誉不摊销，只要不发生减值，就不影响利润；但一旦被收购的企业经营恶化，可能**一次性**计提巨额的减值损失。

同一桩收购，在两套准则下，利润的“时间分布”完全不同。这也是一些频繁收购的日本企业选择 IFRS 的原因之一。当然，按日本会计准则每年摊销，也不能避免“爆雷”：日本邮政 2015 年以约 6,200 亿日元收购澳大利亚的 Toll 公司，2017 年 3 月期就一次性计提了约 4,003 亿日元的减值损失（第 28 章）。

还要注意：**采用 IFRS 的日本企业，“营业利润”的口径与日本会计准则不同。** IFRS 没有“特别损益”，减值损失、出售固定资产的损益等通常计入“其他收益和费用”，包含在营业利润里。所以“分析本业看营业利润”的原则，对 IFRS 企业要打折扣，最好再看它自己公布的“事业利润”“调整后营业利润”等指标，并弄清楚剔除了什么。2027 年起适用的新准则 IFRS 18 会统一定义“营业利润”，并要求企业披露这类“管理层定义的业绩指标”的计算方法。

另一个正在发生的变化是**租赁**。IFRS（2019 年起的 IFRS 16）和美国 GAAP 已经要求承租人把几乎所有的租赁都作为资产和负债计入资产负债表。日本会计准则也在 2024 年 9 月发布了新的租赁会计准则（企業会計基準第 34 号），**从 2027 年 4 月 1 日以后开始的会计年度起强制适用**（3 月决算的公司从 2028 年 3 月期起），允许提前适用。对于租用大量店铺的零售、餐饮企业，以及租用飞机的航空公司，资产和负债会明显增加，自有资本比率等指标会下降——**企业的实际经营没有变化，报表上的数字却变了。**

### “利润”的弹性从哪里来

即使在同一套准则下，利润也包含大量的**估计和判断**：

| 判断的项目 | 管理层可以怎样影响利润 |
| --- | --- |
| 收入确认的时点 | 把下个季度的销售提前确认（例如季末向经销商大量压货） |
| 折旧年限和方法 | 把设备的使用年限从 5 年改为 8 年，每年的折旧费用就会减少 |
| 坏账准备（貸倒引当金） | 少计提坏账准备，今年的利润就多一些，将来的风险就大一些 |
| 存货估值 | 不对卖不出去的存货计提跌价损失 |
| 减值 | 推迟确认商誉、设备等资产的减值 |
| 费用资本化 | 把本应计入费用的支出（如部分开发费用、软件开发费用）记为资产，分期摊销 |
| 准备金和预计负债 | 在业绩好的年份多计提准备金，在业绩差的年份转回，让利润看起来平稳 |

这些判断大多是**合法的**，而且是必要的——会计本来就无法完全避免估计。问题在于，当判断系统性地偏向“让今年的利润好看”时，利润的质量就下降了；越过了界限，就是造假（第 26 章）。

### 三个实用的提醒

1. **看“调整后利润”时要小心。** 很多企业，尤其是美国企业，会在 GAAP 利润之外公布“调整后”（Adjusted）或“非 GAAP”利润，剔除股权激励费用、重组费用、收购相关费用等。有些调整有道理，但如果每年都有“一次性”的费用，它就不是一次性的。
2. **看现金流来交叉验证。** 利润有弹性，现金相对难以操纵（但也不是不可能）。长期来看，好企业的经营现金流应该与净利润大致相当，甚至更高（第 25 章）。
3. **读会计政策和附注。** 会计政策的变更、会计估计的变更、审计师的意见，往往藏在报表的附注里，却是最重要的信息之一。

## 24.6 实战：拆解一家上市公司的年报（日本的“有价证券报告书”与“决算短信”）

### 去哪里找财报

| 市场 | 主要文件 | 去哪里找 |
| --- | --- | --- |
| **日本** | **决算短信**（決算短信）：交易所规则要求的速报，期末后 45 天以内披露（30 天以内更理想），**不需要审计**<br>**有价证券报告书**（有価証券報告書，有報）：金融商品交易法要求的法定文件，期末后 3 个月以内提交，**经过审计**，内容最完整<br>**半期报告书**：2024 年 4 月起，第 1、第 3 季度的法定季度报告书被废止，季度信息统一由交易所的季度决算短信披露，第 2 季度提交半期报告书<br>此外还有决算说明资料、统合报告书、股东大会召集通知 | 决算短信：TDnet（东证的适时披露系统）和公司的 IR 网站<br>有价证券报告书：金融厅的 **EDINET** |
| **美国** | **10-K**（年报）、**10-Q**（季报）、**8-K**（重大事件临时报告）、**DEF 14A**（股东大会委托书，含管理层薪酬） | SEC 的 **EDGAR** |
| **中国** | 年度报告（次年 4 月 30 日前）、半年度报告、季度报告、临时公告 | **巨潮资讯网**（cninfo）、交易所网站；港股在**披露易**（HKEXnews） |

日本企业的一个特点是**决算短信先于有价证券报告书**发布。例如任天堂在 2026 年 5 月 8 日发布了 2026 年 3 月期的决算短信，有价证券报告书则在 6 月 25 日提交，股东大会在 6 月 26 日召开。市场主要根据决算短信做出反应；有价证券报告书则提供更详细的信息：业务风险、分部数据、董事薪酬、大股东、政策持股（交叉持股）的明细等。

### 拆解的步骤：以任天堂为例

下面用任天堂 2026 年 3 月期（2025 年 4 月 – 2026 年 3 月）的决算短信，演示一份财报的阅读顺序。这一年，任天堂在 2025 年 6 月发售了 Nintendo Switch 2，全年销售 1,986 万台。以下数字来自该公司 2026 年 5 月 8 日的决算短信（日本会计准则，合并报表），比率由 python 计算。

**第一步：看封面（サマリー情報）。** 决算短信的第一页汇总了最重要的数字：

| 项目（亿日元） | 2025 年 3 月期 | 2026 年 3 月期 | 变化 |
| --- | --- | --- | --- |
| 营业收入 | 11,649 | 23,131 | +98.6% |
| 营业利润 | 2,826 | 3,601 | +27.5% |
| 经常利润 | 3,723 | 5,422 | +45.6% |
| 归属母公司股东的净利润 | 2,788 | 4,241 | +52.1% |
| ROE（自己資本当期純利益率） | 10.5% | 14.9% | |
| 每股年度股息 | 120 日元 | 219 日元 | |
| 下一年度的公司预测（营业收入 / 净利润） | | 20,500 / 3,100 | −11.4% / −26.9% |

封面上还有**公司对下一年度的业绩预测**（業績予想）。这是日本决算短信的特色，美国企业一般只给出覆盖项目更少、多以区间形式表示的指引（guidance），或者不给。市场的反应往往取决于这个预测和投资者预期的差距，而不只是刚刚结束的那一年。

**第二步：看利润表，问“利润从哪一层来”。**

- **毛利率从约 61% 降到约 39%。** 营业收入翻了一倍，但新主机刚发售的第一年，收入中硬件的比例很高，而硬件的利润率远低于软件。所以收入增长 98.6%，营业利润只增长了 27.5%。
- **经常利润比营业利润多约 1,821 亿日元。** 来源是营业外收益：持分法投资收益 828 亿日元（主要来自持有股份的关联公司，如株式会社 Pokémon）、利息收入 461 亿日元、汇兑收益 443 亿日元。其中汇兑收益取决于日元汇率，不是本业的能力，**不能指望每年都有**。
- **特别利益中有出售投资有价证券的收益 327 亿日元。** 这是一次性的。

结论：分析任天堂的本业，应该主要看营业利润；净利润中有相当一部分来自汇率和一次性项目。

**第三步：看资产负债表，问“钱变成了什么”。**

| 项目（亿日元，2026 年 3 月末） | 金额 | 占总资产 |
| --- | --- | --- |
| 现金和存款 | 17,918 | 47% |
| 有价证券（流动） | 4,251 | 11% |
| 存货 | 5,398 | 14% |
| 应收账款 | 1,475 | 4% |
| 投资有价证券（非流动） | 4,209 | 11% |
| 有形固定资产 | 1,275 | 3% |
| **总资产** | **38,053** | |
| 负债合计 | 8,501 | 22% |
| 净资产合计 | 29,552 | 78% |

任天堂的资产负债表非常“轻”：现金、存款和流动的有价证券约占总资产的近六成（另有约 11% 的投资有价证券，其中包括株式会社 Pokémon 等关联公司的股权，不能视为可以随时动用的资金），工厂设备只占 3%（硬件生产外包给代工厂）。没有需要支付利息的借款，自己资本比率（自有资本比率）达到 77.6%。这样的资产负债表意味着极高的安全性，但也意味着大量的资本没有投入到业务中，会拉低 ROE——这正是第 25 章要讨论的“现金过多”问题。

**第四步：看现金流量表，问“利润有没有变成现金”。**

| 项目（亿日元） | 2025 年 3 月期 | 2026 年 3 月期 |
| --- | --- | --- |
| 经营活动现金流 | 121 | 2,898 |
| 其中：存货的增减 | −3,338 | −276 |
| 投资活动现金流 | +7,531 | −2,101 |
| 其中：购买有形和无形固定资产 | −190 | −272 |
| 筹资活动现金流 | −1,951 | −2,497 |
| 其中：分红 / 回购 | −1,932 / 0 | −1,479 / −999 |

这张表里有两个很好的“教学点”：

1. **2025 年 3 月期，净利润 2,788 亿日元，经营现金流却只有 121 亿日元。** 原因是存货增加了 3,338 亿日元——公司在为 Switch 2 的发售提前备货。这是一个“利润与现金流背离”的例子，但它有清楚、合理的解释，而且第二年随着主机销售，经营现金流恢复到 2,898 亿日元。**背离本身不是问题，找不到解释的背离才是问题**（第 26 章）。不过，2,898 亿日元仍只有当年净利润的约 68%：持分法投资收益（828 亿日元）和汇兑收益（约 619 亿日元）是“没有收到现金”的利润，应收账款也增加了约 748 亿日元。这再次说明，营业外收益不一定是现金。
2. **投资活动现金流的大幅波动，主要不是来自设备投资。** 2025 年 3 月期投资现金流为正 7,531 亿日元，主要是定期存款到期和出售有价证券；真正的设备和软件投资每年只有 200–300 亿日元。对任天堂这样现金很多的公司，投资活动现金流里混杂着大量的“资金运用”，计算自由现金流时，应该用经营现金流减去设备投资，而不是直接用“经营现金流 + 投资现金流”。按前一种算法，2026 年 3 月期的自由现金流约为 2,898 − 272 ≈ 2,626 亿日元。

**第五步：检查勾稽关系。** 利益剰余金从 27,325 亿日元增加到 29,799 亿日元，增加了 2,474 亿日元；而净利润是 4,241 亿日元。差额 1,767 亿日元，主要是分红（约 1,479 亿日元）和注销库存股：注销的约 291 亿日元先冲减资本剰余金，不足的约 288 亿日元再从利益剰余金中扣除。注意，**回购本身（约 999 亿日元）不减少利益剰余金**，只是增加了净资产中的扣减项“自己株式”。数字对得上，就说明我们理解了这些钱的去向。

**一个容易困惑的地方：现金对不上？** 樱花咖啡的例子里，现金流量表的现金增减等于资产负债表上现金的变化。但任天堂的现金流量表显示“现金及现金等价物”**减少**了约 974 亿日元，而资产负债表上的“现金及存款”却**增加**了约 2,055 亿日元。原因有二：①现金流量表中的“现金等价物”不包括存期超过 3 个月的定期存款（任天堂有约 7,754 亿日元），却包括 3 个月内到期的短期投资，两者的口径不同（决算短信的注记中有调节表）；②外币现金因汇率变化产生了约 725 亿日元的换算差额。读真实的财报时，要先确认口径，再做勾稽。

**第六步：读文字和附注。** 决算短信的“经营成果概况”说明了业绩变化的原因；“利润分配的基本方针”说明了分红政策（任天堂从 2026 年 3 月期的期末股息起，把分红标准改为“合并营业利润的 40%”或“合并派息率 60%”中较高的一个）；决算说明会的问答记录则透露了管理层对下一年度的判断——例如任天堂预计，内存等零部件涨价和关税将使下一年度的成本增加约 1,000 亿日元；公司也以零部件价格、汇率等市场环境的变化为由，决定上调 Switch 2 的售价。这些信息不在三张表里，却对理解未来的利润很重要。

**第七步：需要更多细节时，读有价证券报告书。** 例如“事业等风险”、董事报酬、大股东名单、政策持股的明细，以及审计报告中的“关键审计事项”（KAM）。

### 一份财报的检查清单

| 问题 | 看哪里 |
| --- | --- |
| 收入和利润增长的原因是什么？可持续吗？ | 决算短信的经营概况、分部信息、决算说明资料 |
| 利润来自本业还是一次性项目？ | 利润表的各层利润、营业外和特别项目 |
| 利润有没有变成现金？ | 经营现金流 vs 净利润；应收账款、存货的变化 |
| 钱投到了哪里？回报如何？ | 资产负债表的结构、投资活动现金流、ROE / ROIC（第 25 章） |
| 财务安全吗？ | 现金、有息负债、自有资本比率（第 25 章） |
| 赚到的钱怎么分配？ | 分红、回购的金额和政策（第 28 章） |
| 管理层怎么看未来？可信吗？ | 业绩预测、过去预测的准确程度、说明会问答 |
| 有没有会计政策变更、审计意见的异常？ | 附注、审计报告、有价证券报告书 |

## 常见误区

| 误区 | 实际情况 |
| --- | --- |
| “利润就是公司赚到的现金” | 利润按权责发生制计算，包含应收账款、折旧等非现金项目；利润和经营现金流在单个年度可能相差很大。 |
| “净资产（内部留保）就是公司手里的现金” | 净资产是资产减负债后的账面差额，留存收益可能早已变成了设备、存货或子公司股权。 |
| “资产负债表上的数字就是资产的真实价值” | 大部分资产按历史成本减折旧记账；自己培养的品牌、技术等往往不在表上。 |
| “经常利润（或净利润）增长，说明本业变好了” | 经常利润包含利息、汇兑损益等，净利润还包含一次性项目；判断本业要看营业利润及其来源。 |
| “会计准则是统一的，利润可以直接比较” | 日本会计准则、IFRS、美国 GAAP 在商誉、租赁、一次性项目等方面不同；同一准则下也有大量估计和判断。 |
| “决算短信经过了审计，可以完全信赖” | 决算短信不是审计的对象；经过审计的是有价证券报告书中的财务报表。 |

## 本章小结

- 资产负债表是某一时点的快照：资产 = 负债 + 净资产；利润表记录一段时间的经营成果；现金流量表记录现金的实际流动，分为经营、投资、筹资三类。
- 日本的利润表有毛利、营业利润、经常利润、净利润等多层利润；分析本业主要看营业利润，并把一次性项目剔除出去。
- 权责发生制让利润更好地反映经营成果，但也让利润与现金产生差异，并给管理层的判断留下空间。
- 三张表通过留存收益、现金、营运资金和折旧等勾稽关系相互咬合，检查这些关系是发现问题的重要方法。
- 日本会计准则、IFRS、美国 GAAP、中国企业会计准则在商誉摊销、一次性项目、租赁等方面存在差异；比较企业前要先确认口径。
- 日本上市公司的财报主要看决算短信（TDnet，未经审计、速报）和有价证券报告书（EDINET，经过审计、最完整）；美国看 EDGAR，中国看巨潮资讯网。
- 拆解财报的顺序：封面 → 利润表（利润从哪一层来）→ 资产负债表（钱变成了什么）→ 现金流量表（利润有没有变成现金）→ 勾稽关系 → 文字和附注。

## 思考与练习

1. 樱花咖啡第 2 年的情况如下：销售额 3,600 万日元，年底应收账款从 200 万增加到 500 万；营业成本 1,440 万，存货和应付账款都没有变化；工资房租等 1,100 万；折旧仍为 240 万；年初还清了全部借款 500 万（本年不再有利息）；税率 30%；分红 150 万。请计算第 2 年的净利润、经营活动现金流和年底的现金余额。
2. 某公司的利润表显示，净利润连续三年每年增长 20%，但经营现金流三年都是负的，同时应收账款每年增长 50%。你会提出哪些问题？有哪些可能的解释是合理的，哪些是危险信号？
3. A 公司（采用日本会计准则）和 B 公司（采用 IFRS）业务相似，营业利润都是 100 亿日元。A 公司每年有 30 亿日元的商誉摊销，B 公司有相同规模的商誉但不摊销。如果你要比较两家公司的盈利能力，应该怎样调整？B 公司的商誉有什么风险？
4. 任天堂 2026 年 3 月期的经常利润（5,422 亿日元）比营业利润（3,601 亿日元）多约一半。请列出差额的主要来源，并说明在预测它下一年度的利润时，哪些部分应该谨慎对待。
5. 一位朋友说：“日本企业的内部留保有 600 多万亿日元，应该全部拿出来给员工涨工资。”请从资产负债表的角度，说明这句话的问题在哪里。

::: details 参考思路
1. 利润表：营业利润 = 3,600 − 1,440 − 1,100 − 240 = 820 万；没有利息，税前利润 820 万；税 246 万；净利润 574 万。经营现金流 = 574 + 240（折旧）− 300（应收账款增加）= 514 万。投资现金流为 0；筹资现金流 = −500（还款）− 150（分红）= −650 万。现金余额 = 640 + 514 − 650 = 504 万日元。可以验证：留存收益 = 250 + 574 − 150 = 674 万，净资产 1,674 万；资产 = 现金 504 + 应收 500 + 存货 100 + 设备 720 = 1,824 万；负债 = 应付账款 150 万；1,674 + 150 = 1,824，两边相等。
2. 应该问：收入增长来自哪些客户？是否放宽了信用条件（延长账期）来换取销售？应收账款的账龄结构如何，有没有长期收不回的？坏账准备是否充分？有没有大客户是关联方？合理的解释包括：新开拓了账期较长的大客户、行业惯例是年底集中交货等，但这些解释应该能在附注和说明资料中得到印证，而且不应该年复一年地持续。危险信号包括：应收账款的增长持续远快于收入、客户集中于不知名的公司或关联方、坏账准备比例下降、频繁更换审计师等（第 26 章）。
3. 可以把 A 公司的商誉摊销加回去，即比较“摊销前”的营业利润（A 公司约 130 亿日元，B 公司 100 亿日元），或者反过来，对 B 公司假设同样的摊销。调整后，A 公司的本业盈利能力实际上更高。B 公司的风险在于：商誉不摊销，并不代表它不会贬值；如果被收购的业务表现不佳，B 公司可能一次性计提巨额减值，利润会突然大幅下降。
4. 主要来源：持分法投资收益约 828 亿日元，利息收入约 461 亿日元，汇兑收益约 443 亿日元，再减去少量营业外费用。持分法收益取决于关联公司（如株式会社 Pokémon）的业绩，有一定的持续性，但会随游戏和电影等作品的周期波动；利息收入取决于现金规模和利率；汇兑收益取决于期末的汇率，方向和大小都难以预测，最应该谨慎对待。公司自己对下一年度的预测是经常利润 4,300 亿日元，比本年度减少约 20%，而营业利润预计增加 2.7%，说明公司也没有假设营业外收益会持续。
5. “内部留保”通常指资产负债表上的利益剰余金（留存收益），它是历年利润扣除分红后的累计额，是净资产的一部分，不是现金。根据财务省的法人企业统计，2025 年度末日本企业（不含金融保险业）的利益剰余金约 655 万亿日元，而企业持有的现金和存款只有约 300 万亿日元的规模，不到利益剰余金的一半：留存收益中很大一部分已经变成了设备、存货、对子公司的投资等。至于企业是否持有过多的现金、应该怎样使用，是另一个值得讨论的问题（第 25 章、第 28 章），但不能把留存收益直接等同于“可以拿出来的钱”。
