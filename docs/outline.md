# 全书目录

> 本书共 **11 个部分、55 章**，外加附录。每章标注了难度：🟢 入门 · 🟡 进阶 · 🔴 深入。
> 「案例」为该章计划使用的真实历史事件，正文撰写时会逐一核实时间、数据与出处。
> 本书覆盖**日本、中国、美国**三个市场。考虑到读者生活在日本，实务部分会以日本的制度（NISA、iDeCo、特定口座等）为主。
