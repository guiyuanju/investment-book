# 第47章 建立投资纪律 🟢

> 第九部分 · 投资者心理与行为金融

::: tip 学习目标
读完本章，你应该能够：
- 理解为什么“知道偏差”不够，需要用流程和制度来对抗偏差
- 为买入、卖出和市场动荡制定简单的投资清单
- 建立投资日志，用事前的记录对抗后见之明偏差，并定期复盘
- 区分决策质量和结果质量，不被短期的运气误导
- 用自动化、默认选项和事先写好的规则，让纪律不依赖于当时的意志力
:::

第 45 章和第 46 章讨论了个人的认知偏差和群体心理。读完之后，一个自然的想法是：“我已经知道这些偏差了，以后注意就好。”

遗憾的是，这几乎没有用。卡尼曼研究了几十年的偏差，他说自己的直觉并没有因此改善多少。偏差来自快速、自动的系统 1，而在市场暴跌、新闻全是坏消息的时候，系统 1 的声音最大。**在那一刻依靠意志力去对抗它，很可能会失败。**

更有效的方法，是在冷静的时候，提前设计好流程和制度，让它们在情绪激动的时候替你做决定。古希腊史诗《奥德赛》中，英雄奥德修斯（Ulysses）知道自己听到海妖塞壬的歌声后会失去理智，于是事先让水手把自己绑在桅杆上，并命令他们无论自己怎样请求，都不要松绑。这种“事先约束未来的自己”的做法，叫作**预先承诺**（Precommitment／プリコミットメント）。

本章介绍四种工具：投资清单、投资日志、区分决策与结果，以及规则化。

## 47.1 投资清单（Checklist）

### 清单的力量：从飞机到手术室

1935 年 10 月 30 日，波音公司的新型轰炸机原型机 Model 299 在美国陆军的测试飞行中，起飞后不久失速坠毁，两名机组人员死亡，其中包括经验丰富的试飞员。调查发现，事故的原因不是飞机的结构或机械故障，而是机组忘记解除升降舵等操纵面的锁定装置。这架飞机比以往的飞机复杂得多，人的记忆已经无法可靠地处理所有的步骤。

之后，试飞员们设计了一份简单的**检查清单**，把起飞、飞行、着陆前必须确认的步骤逐项列出来。这架飞机后来发展成了 B-17 轰炸机。检查清单从此成为航空业的标准做法。

医学也有类似的例子。世界卫生组织推广了一份 19 项的手术安全清单。2009 年发表在《新英格兰医学杂志》上的研究，在全球 8 个城市的 8 家医院比较了引入清单前后的结果：手术后的死亡率从 **1.5%** 降到 **0.8%**，住院期间的并发症从 **11.0%** 降到 **7.0%**。外科医生葛文德（Atul Gawande）在 2009 年出版的《清单革命》（The Checklist Manifesto）中，介绍了这些故事。

需要客观地补充：这项研究比较的是引入前后的变化，不是随机对照试验。2014 年，加拿大安大略省对 101 家医院的大规模研究发现，强制推行清单之后，死亡率和并发症并没有显著下降。一种解释是：**清单的效果，取决于它是否被认真执行，而不是是否存在**。只为了应付检查而打勾的清单，没有什么用。

### 清单为什么对投资有用

投资中的错误，大多不是因为缺乏知识，而是因为**在某个时刻忘记了、跳过了、或者被情绪推着跳过了**自己本来知道的东西。清单的作用是：

1. 把冷静时的判断，带到不冷静的时刻；
2. 强制你回答那些你不想回答的问题（例如“我可能错在哪里”）；
3. 放慢速度，给系统 2 一个检查系统 1 的机会。

好的清单应该**短**（通常 5–10 项）、**具体**（可以回答“是”或“否”，或者写出一个数字），并且只包含**最容易被忽略、而后果最严重**的项目。

### 示例一：买入一只基金之前

对于大多数在日本用 NISA 做长期投资的人，最常见的决定是买入一只投资信托。一个简单的清单：

| 问题 | 我的回答 |
| --- | --- |
| 这只基金投资于什么？我能用一两句话向别人说明吗？ | |
| 它在我的整体配置中扮演什么角色？买入后，股票的比例是多少？（第 41 章） | |
| 总费用是多少？（信托报酬，以及买入手续费、信托财产留保额；第 9 章、第 35 章、第 44 章） | |
| 是否有更便宜、几乎相同的替代品？ | |
| 是每月分配型、主题型或杠杆型吗？如果是，我理解它的风险吗？（第 9 章、第 43 章） | |
| 我是因为最近的业绩好、媒体或社交媒体上很热门才想买的吗？（第 45 章、第 46 章） | |
| 如果它在一年内下跌 30–40%，我会怎么做？ | |

### 示例二：买入一只个股之前

| 问题 | 我的回答 |
| --- | --- |
| 这家公司怎样赚钱？竞争优势是什么，能持续多久？（第 27 章） | |
| 财务报表中有没有危险信号？（第 24–26 章） | |
| 用至少一种方法估算价值，现在的价格有没有安全边际？（第 30–32 章） | |
| **我可能错在哪里？什么情况发生时，说明我的判断是错的？** | |
| 买入后，这只股票占我总资产的比例是多少？是否超过了自己设定的上限？ | |
| 我是否认真读过最有说服力的反方观点？ | |

其中最重要的一项，是写下“**什么情况发生时，说明我错了**”。这能对抗确认偏误和处置效应（第 45 章）：将来股价下跌时，你检查的是这些条件是否出现，而不是只盯着自己的买入价格。

心理学家克莱因（Gary Klein）在 2007 年提出了一个相关的方法，叫“**事前验尸**”（Premortem）：在做决定之前，假设三年后这笔投资彻底失败了，然后写下失败的原因。人们在“已经失败了”的假设下，往往能想到更多平时会被忽略的风险。

### 示例三：市场动荡时，想卖出之前

这份清单也许是最有价值的，因为它针对的正是情绪最激动的时刻：

| 问题 | |
| --- | --- |
| 我想卖出，是因为价格下跌了，还是因为我的生活、目标或资金需求发生了变化？ | |
| 我的长期计划（第 53 章）里，有没有写到这种情况下应该怎么做？ | |
| 如果今天从零开始，我还会选择同样的资产配置吗？（个股可以问：如果今天手里是现金，我还会买入它吗？第 45 章） | |
| 卖出之后，我打算在什么条件下买回？（择时需要做对两次，第 44 章） | |
| 在应税账户中卖出，要缴多少税？ | |
| 我能否等 48 小时，或者等到周末再做决定？ | |

如果第一个问题的答案是“因为价格下跌了”，而计划中没有写“价格下跌就卖出”，那么最好的选择通常是：**什么都不做**，或者按照计划进行再平衡。

## 47.2 投资日志与事后复盘

### 后见之明偏差：记忆会改写过去

**后见之明偏差**（Hindsight Bias／後知恵バイアス）是指知道结果以后，人们会觉得这个结果“早就可以预见”，并且会不自觉地改写自己当时的想法。心理学家菲施霍夫（Baruch Fischhoff）在 1975 年的实验中发现：知道了结果的人，会高估自己事先能够预测这个结果的可能性。这也被称为“**我早就知道**”效应。

在投资中，后见之明偏差让人很难从经验中学习：

- 股票上涨了，你会记得自己“当时就很有把握”；
- 股票下跌了，你会记得自己“当时就有点担心”；
- 2024 年 8 月 5 日暴跌之后，很多人觉得“当时的日元套息交易显然要平仓了”；但在 8 月初，市场上几乎没有人预测到一天下跌 12%（第 19 章）。

如果你的记忆在不断地改写，你就无法知道自己的判断到底是准还是不准。**解决方法只有一个：在做决定的时候就写下来。**

### 记录什么

投资日志不需要复杂。每次做出重要的投资决定（买入、卖出、改变配置）时，花 10 分钟记录：

| 项目 | 示例 |
| --- | --- |
| 日期和操作 | 2026 年 3 月 10 日，在 NISA 成长投资额度中买入某日本股票 50 万日元 |
| 理由（为什么现在、为什么是它） | 股价因短期的业绩下修下跌了 25%，但核心业务的竞争力没有变化，预期市盈率 12 倍，低于过去 10 年的平均水平 |
| 我的预期 | 3 年内，有约 60% 的可能性跑赢 TOPIX |
| 什么情况说明我错了 | 核心业务的市场份额连续两年下降；或者管理层把现金用于高价收购 |
| 仓位 | 买入后占金融资产的 4%（我的上限是单只个股 5%） |
| 信息来源 | 公司的决算说明资料、有价证券报告书 |
| 当时的情绪（1–10） | 兴奋 6；对“错过低价”的焦虑 4 |

最后一项“当时的情绪”看起来奇怪，但很有用。复盘时你可能会发现：**在兴奋或焦虑程度很高时做出的决定，结果明显更差**。

### 怎样复盘

建议每年复盘一次（不要在市场剧烈波动时复盘）。复盘时：

1. **对照当时的记录**，而不是你的记忆。当时的理由成立了吗？“说明我错了”的条件出现了吗？
2. **分开评价决策和结果**（47.3 节）。赚钱的决定，可能是运气；亏钱的决定，可能是合理的。
3. **检查你的预测是否“校准”**：如果你多次写下“约 60% 的可能性”，那么这些预测中，是否大约有 60% 实现了？如果你说“60%”的事情只有 30% 实现了，说明你过度自信（第 45 章、第 49 章）。但预测的次数太少时，无法判断是否校准：只有 10 次“60%”的预测，实现 4 次也完全可能只是运气（参见 47.3 节的赌局）。
4. **和简单的基准比较**：把你的实际回报（考虑资金进出的时间，即资金加权回报），与“一直持有全球股票指数基金”或“按计划定投”的结果比较。如果多年来你的主动操作一直跑输简单的方法，这本身就是最重要的复盘结论（第 35 章、第 44 章）。
5. **寻找模式，而不是单个事件**：你是否总在大跌后卖出？总在热门的时候买入？你的错误是否集中在某一类决定上？

在日本，按照日本证券业协会和投资信托协会的规则，销售机构需要定期向客户通知所持投资信托的“トータルリターン”（考虑了分配金和已实现损益的累计损益；对象是 2014 年 12 月以后买入的部分），很多网络券商也在账户页面显示，可以作为复盘的起点。计算资金加权回报，可以用电子表格的 XIRR 函数。

## 47.3 区分决策质量与结果质量

### 好决策可能有坏结果

第 1 章提到：买彩票中了奖，不能说明买彩票是好决策。这背后是一个重要的原则：**在不确定的世界里，决策的质量和结果的质量是两回事**。

| | 好的结果 | 坏的结果 |
| --- | --- | --- |
| **好的决策** | 应得的回报 | 运气不好 |
| **坏的决策** | 运气好（最危险） | 应得的教训 |

最危险的是左下角：**坏的决策带来了好的结果**。它会强化错误的做法，让你下次用更大的金额重复同样的错误。用杠杆集中买入一只股票而大赚的人，很少认为自己只是运气好（第 43 章）。

### 数值例子：有优势的赌局也会亏钱

假设有一个赌局：每次投入 1 万日元，60% 的概率赢 1 万日元，40% 的概率输 1 万日元。每次的期望值是 +0.2 万日元，这显然是一个“好的决策”。但如果只玩有限的次数（python 计算）：

| 玩的次数 | 最后亏钱的概率 | 最后正好不赚不亏的概率 |
| --- | --- | --- |
| 1 次 | 40.0% | — |
| 10 次 | 16.6% | 20.1% |
| 20 次 | 12.8% | 11.7% |
| 100 次 | 1.7% | 1.0% |

即使有明显的优势，玩 10 次之后，仍有约六分之一的概率是亏钱的。**次数越少，运气对结果的影响越大。**

投资也是一样。持有分散的股票指数，长期的期望回报为正，是一个合理的决定。但第 45 章的数据显示，美国股市约 27% 的年份是下跌的。在一个下跌的年份结束时，你不能因此说“买指数基金是错误的决定”。

### 结果偏差

**结果偏差**（Outcome Bias／結果バイアス）是指根据结果来评价决策的好坏。巴伦（Jonathan Baron）和赫尔希（John Hershey）在 1988 年的实验中，给受试者看别人在不确定条件下做出的决定（例如是否进行一项有风险的手术），以及决定的结果。即使决定时掌握的信息完全相同，**结果好的决定，也被评价为思考质量更高、决策者更有能力**。

扑克牌选手出身的作家杜克（Annie Duke）在 2018 年出版的《对赌》（Thinking in Bets）中，举了一个美式橄榄球的例子：2015 年 2 月的第 49 届超级碗，西雅图海鹰队落后 4 分，比赛剩下 26 秒，球在对方的 1 码线上。教练卡罗尔（Pete Carroll）没有让最擅长冲球的跑卫持球强攻，而是选择了传球，结果球被对方截获，比赛输掉。第二天，媒体普遍称之为“超级碗历史上最糟糕的决定”。

杜克认为，从当时的时间、暂停次数和传球被截获的历史概率来看，这个选择是有道理的，只是结果非常糟糕。如果那次传球成功了，没有人会批评这个决定。这个决定到底好不好，至今仍有争议，但这正说明了：**评价决策，应该看决策时的信息和推理，而不是只看结果**。

### 在投资中的应用

1. **评价自己的决定**：复盘时问“根据当时的信息，这个决定合理吗？”而不是“我赚钱了吗？”
2. **评价基金经理和投资建议**：一位基金经理 1–3 年的业绩，很大程度上可能是运气（第 16 章、第 35 章）。要看他的方法是否合理、是否一致、费用是否合理。
3. **评价别人的成功故事**：一个人在 2020 年把全部资产投入某只股票，翻了 5 倍，不代表这是好的决策（第 45 章的幸存者偏差）。
4. **不要因为一次坏结果而放弃好的方法**：2022 年股票和债券同时下跌，60/40 组合表现很差（第 41 章）。这不能说明分散投资是错误的，只说明它不能在每一年都起作用。

“决策质量”和“结果质量”的区分，是概率思维的核心之一。第 49 章会从期望值和概率的角度更深入地讨论。

## 47.4 规则化：用制度对抗情绪

### 默认选项的力量

行为经济学的一个重要发现是：**人们倾向于维持现状，接受默认选项**。这既是问题，也可以变成工具。

- **自动加入**：马德里安（Brigitte Madrian）和谢伊（Dennis Shea）在 2001 年研究了美国一家公司的 401(k) 养老金计划。在员工需要主动申请才能加入的时期，新员工的加入率约为 **37%**；改为“自动加入，不想参加的人可以申请退出”后，新员工的加入率上升到约 **86%**。员工的选择自由完全一样，变的只是默认选项。但这项研究也显示了默认选项的另一面：很多自动加入的员工，一直停留在公司设定的较低的默认缴费率和保守的默认商品（货币市场基金）上。**默认选项是双刃剑**，它会让人“什么都不做”，无论默认的是好是坏。
- **明天存更多**（Save More Tomorrow）：塞勒和贝纳茨设计了一个方案：员工事先同意，**将来每次加薪时**，自动提高养老金的缴费率。因为提高缴费发生在未来，而且不会让到手的工资减少，所以人们更容易接受。在第一家实施的公司，参加者的缴费率在约 40 个月（4 次加薪）中从 **3.5%** 提高到 **13.6%**，约八成的人一直留在计划中（2004 年发表）。

这些研究带来的启示是：**与其依靠每个月的意志力，不如设计一个“什么都不做也会做对”的环境**。

### 在日本可以使用的“自动化”工具

| 工具 | 作用 | 需要注意 |
| --- | --- | --- |
| NISA 的定期定额自动买入（つみたて設定，可以用银行账户或信用卡扣款） | 每月自动投资，不需要每次决定“现在是否该买” | 设定之后不要频繁更改；定期检查一下金额是否还合适 |
| iDeCo（个人型确定缴费养老金） | 每月自动缴费；原则上 60 岁之前不能取出，这本身是一种预先承诺。2026 年 12 月起，加入年龄的上限提高到 70 岁之前，缴费上限也提高（公司职员每月最多 6.2 万日元） | 缴费可以停止，但已积累的资产仍被锁定，应急资金要另外准备（第 5 章）；制度细节和外国籍居民离开日本时的处理见第 52 章 |
| 企业型 DC 的“指定运用方法” | 员工没有选择时，资金自动投入公司事先指定的商品 | 默认商品不一定适合你，有时是定期存款等保本型商品，需要主动检查 |
| 工资的自动转账（先存后花） | 发工资当天自动转入投资或储蓄账户 | 适合几乎所有人 |

### 写下你的规则

除了自动化，还可以事先写下自己的投资规则。第 53 章会详细介绍完整的“投资政策说明书”（IPS），这里先列出几条最重要的规则：

1. **目标配置和再平衡**：例如“股票 70%、债券 30%；每年 1 月检查一次，偏离 5 个百分点以上时，用新增资金或卖出调整”（第 44 章）。
2. **什么情况下卖出**：例如“只在以下情况卖出：①需要用钱；②再平衡；③个股的‘说明我错了’的条件出现”。**价格下跌本身不是卖出的理由。**
3. **集中度的上限**：例如“单只个股不超过金融资产的 5%；公司股票（包括持股会）不超过 10%”（第 40 章）。
4. **不使用杠杆**（第 43 章）。
5. **冷静期**：任何不在计划内的交易，都要等 48 小时以上再执行。
6. **查看的频率**：例如“每季度查看一次账户；关闭价格通知”（第 44 章、第 45 章）。

### 事先写好危机预案

规则在平时很容易遵守，真正的考验是在危机中。所以，最好事先写下：**如果我的资产大幅下跌，我会怎么做？**

**数值例子**：你有 1,000 万日元，配置是股票 80%、债券 20%。假设股票下跌 50%，债券不变（python 计算）：

- 股票从 800 万日元变成 400 万日元，总资产从 1,000 万日元变成 **600 万日元，下跌 40%**；
- 这时股票只占 400 ÷ 600 ≈ 67%。如果按照规则再平衡回 80%，需要把约 **80 万日元**的债券换成股票，也就是在最恐慌的时候买入。

在冷静的时候，问自己两个问题：

1. 看到账户里少了 400 万日元，我能承受吗？如果不能，现在就应该降低股票的比例，而不是等到暴跌时再卖出（第 41 章）。
2. 在那个时候，我真的会按规则买入吗？如果不确定，可以事先写一句话给未来的自己，例如：“你在 2026 年写下这个计划时就知道会有这一天。按计划执行，然后关掉手机。”

这种“如果……就……”的写法，心理学上称为**执行意图**（Implementation Intention／実行意図），由心理学家戈尔维策（Peter Gollwitzer）提出。戈尔维策和希兰（Paschal Sheeran）2006 年对 94 项检验的荟萃分析发现，把计划写成具体的“如果出现 X，我就做 Y”，比笼统的“我要坚持”更容易被执行，效果属于中等到较大的程度。

### 规则也需要检查

规则不是一成不变的。需要注意：

- **规则可能是错的**。例如，股票比例对你来说太高，你在暴跌中坚持不下去。规则应该定期检查和修改。
- **修改规则的时机**：只在冷静的时候（例如每年的固定时间）修改，不在市场剧烈波动的时候修改。在暴跌中“修改规则”，往往只是恐慌卖出的另一种说法。
- **生活的变化优先于市场的变化**：结婚、生子、换工作、买房、退休，都是重新检查规则的正当理由（第 53 章）。
- **机构投资者也依靠规则**：日本的 GPIF 用事先确定的基本投资组合和偏离容许幅度管理资产，在市场大跌时按规则再平衡（第 38 章、第 44 章）。

## 常见误区

| 误区 | 实际情况 |
| --- | --- |
| “我已经了解了认知偏差，靠意志力就能避免” | 偏差来自快速、自动的思考，在情绪激动时最强。有效的是事先设计好的流程和制度 |
| “清单是给新手用的” | 飞行员和外科医生都在使用清单。清单的作用是防止在压力下遗漏本来知道的东西 |
| “我记得自己当时为什么买入” | 后见之明偏差会改写记忆。只有当时写下的记录才可靠 |
| “赚钱了，说明我的决定是对的” | 结果受运气影响。根据决策时的信息和推理评价决策，而不是只看结果 |
| “自动定投太死板，应该根据市场灵活调整” | 灵活调整，往往意味着在情绪的影响下追涨杀跌。自动化让你在不想买的时候也能按计划买入 |
| “规则一旦定下就不能改” | 规则应该定期检查，但只在冷静的时候修改，而且生活的变化优先于市场的变化 |

## 本章小结

- 知道偏差的存在，不能让人免疫。更有效的方法是预先承诺：在冷静时设计好流程和制度，让它们在情绪激动时替你做决定。
- 投资清单把冷静时的判断带到不冷静的时刻。最重要的清单是“想卖出之前”的清单，以及写下“什么情况说明我错了”。
- 投资日志对抗后见之明偏差。记录理由、预期、错误的条件和当时的情绪，每年复盘一次，并与简单的基准比较。
- 决策质量和结果质量是两回事。有优势的决策短期也可能亏钱；坏的决策带来好的结果，是最危险的情况。
- 默认选项和自动化非常有效。在日本，可以利用 NISA 的自动定投、iDeCo 和工资的自动转账，再加上事先写好的规则和危机预案。
- 规则需要定期检查，但只在冷静的时候修改；生活的变化优先于市场的变化。
