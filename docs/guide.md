# 阅读指南

## 本书是写给谁的

- 没有金融背景，但想系统了解投资的人
- 已经买过股票或基金，但觉得自己“知其然不知其所以然”的人
- 想从零散知识走向一套完整投资框架的人

| 你的情况 | 建议路径 |

## 每章的结构

每一章都按统一的结构编写：

1. **学习目标**：读完本章你应该能够理解或做到什么
2. **核心概念**：定义、原理，必要时给出公式和数值示例
3. **真实案例**：用历史事件说明概念，注明时间、数据与出处
4. **常见误区**：初学者容易产生的误解
5. **本章小结**：几条要点
6. **思考与练习**：帮助你检验理解、迁移应用

## 写作原则

1. **准确优先**：概念以权威教材、监管机构和学术文献的口径为准。不能确定的数据宁可不写。
2. **事实与观点分开**：有共识的结论直接陈述；有争议的问题（如有效市场、技术分析、价值风格的未来）会列出不同观点及各自的证据。
3. **数据可追溯**：引用的数据注明来源与统计口径（时间区间、是否含分红、名义或实际收益）。
4. **覆盖日中美三个市场**：制度和例子同时覆盖日本、中国（A 股、港股）和美国市场，并说明差异。实务部分以日本的制度为主。
5. **术语中英日对照**：重要术语第一次出现时给出英文，必要时也给出日文，例如“久期（Duration／デュレーション）”，方便读者查阅外文资料。
6. **警惕幸存者偏差**：讲成功案例的同时也讲失败案例，不把个别投资者的成功当成普遍规律。
7. **客观对待各国市场**：讲某个市场的问题时（例如 A 股长期回报偏低的争议），先摆数据和制度事实，再分析原因，并说明哪些情况正在改变，不给出笼统的“好”或“坏”的评价。
